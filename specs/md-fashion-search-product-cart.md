# Тест-план MD Fashion: поиск, карточка товара, корзина (без оформления заказа)

## Application Overview

Сайт https://md-fashion.ua/ (интернет-магазин одежды, интерфейс по умолчанию на украинском, переключатель «Українська / Російська» в шапке). Область: поиск через поле «Пошук» в шапке, страница товара, корзина (/cart/index). ЗАПРЕЩЕНО: «Оформити замовлення», ввод персональных данных, вход/регистрация/подписки. Попапы cookies/языка/промо при загрузке главной не обнаружены; если появятся — закрыть крестиком/«Прийняти» и продолжить. Поиск: URL вида /store?s=<запрос>. Реальные тестовые данные: товар «Жіноча чорна сукня SLIM 5X2 RIB» Tommy Hilfiger, артикул WW0WW46138, URL /store/zhinocha-chorna-suknya-slim-5x2-rib-tommy-hilfiger-ww0ww46138-chornyi (цена на момент исследования 6 853 грн, старая 9 790 грн, -30%, размеры XXS, XS, S, M, L). Цены/наличие меняются (Black Friday) — сверять значения между экранами, а не с константами. Каждый сценарий начинается с чистого состояния: новый контекст браузера, пустая корзина.

## Test Scenarios

### 1. 1. Поиск товара

**Seed:** `tests/seed.spec.ts`

#### 1.1. 1.1 Поиск по существующему запросу «сукня» (Enter)

**File:** `tests/search/search-existing.spec.ts`

**Steps:**
  1. Открыть https://md-fashion.ua/ (при наличии попапа закрыть его). Кликнуть в поле «Пошук» в шапке и ввести «сукня».
    - expect: Под полем открывается выпадающий блок с секциями «Товари», «Категорії» (Сукні, Сукні-толстовки, Сукні-сорочки…), «Пропозиції» (сукня вечірня, сукня джинсова…), «Бренди» и ссылкой «Всі результати пошуку»
  2. Нажать Enter.
    - expect: URL /store?s=%D1%81%D1%83%D0%BA%D0%BD%D1%8F
    - expect: Заголовок «Каталог всіх товарів | Інтернет-магазин MD-Fashion»
    - expect: Показана сетка товаров, названия содержат «сукня»/«сарафан», счётчик вида «27 з 1631 товара», кнопка «Показати ще» и пагинация 1…61
    - expect: У каждой карточки есть бренд, название, цена; у уцененных — старая цена и бейдж «-30%»
