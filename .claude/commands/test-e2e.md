Входные данные от пользователя: $ARGUMENTS

Выполни полный цикл последовательно, дожидаясь завершения каждого этапа:

1. **План** — выполни шаги из `.claude/commands/test-plan.md` с этими входными данными (агент `playwright-test-planner`). Запомни путь к сохранённому плану.
2. **Генерация** — выполни шаги из `.claude/commands/test-generate.md` для этого плана (агент `playwright-test-generator`, по одному сценарию за раз, последовательно).
3. **Починка** — выполни шаги из `.claude/commands/test-heal.md` для папок/файлов, созданных на шаге 2 (агент `playwright-test-healer`).

Если этап завершился ошибкой — остановись и сообщи, на каком этапе и почему.

Итоговый отчёт: путь к плану, список созданных тестов, результат прогона (passed / fixed / fixme).
