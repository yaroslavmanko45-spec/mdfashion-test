Запусти субагента `playwright-test-planner` через Agent tool (subagent_type: "playwright-test-planner").

Входные данные от пользователя: $ARGUMENTS

Передай агенту задачу:
- Цель исследования: URL / раздел / функциональность из входных данных. Если не указано — главная страница приложения.
- Seed-файл: `tests/seed.spec.ts`.
- Сохранить план через `planner_save_plan` в папку `specs/`. Если пользователь указал имя файла — использовать его, иначе `specs/<kebab-case-область>.md`.
- Каждая группа сценариев в плане должна содержать строку `**Seed:** \`tests/seed.spec.ts\``.
- Покрыть happy path, граничные случаи и негативные сценарии; сценарии независимы друг от друга.

После завершения агента кратко сообщи пользователю: путь к сохранённому плану, количество групп и сценариев, и предложи следующий шаг — `/test-generate <путь к плану>`.
