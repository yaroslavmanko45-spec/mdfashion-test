---
description: Сгенерировать Playwright-тесты по тест-плану (агент playwright-test-generator)
argument-hint: <путь к плану в specs/> [номер группы или сценария, напр. 1 или 1.2]
---

Входные данные от пользователя: $ARGUMENTS

1. Прочитай указанный план (первый аргумент). Если план не указан — возьми единственный `.md` из `specs/` кроме `README.md`; если их несколько, спроси пользователя, какой использовать.
2. Если указан фильтр (номер группы `N` или сценария `N.M`) — оставь только соответствующие сценарии, иначе — все.
3. Для каждого сценария запусти субагента `playwright-test-generator` (subagent_type: "playwright-test-generator") и передай ему:
   - `<test-suite>` — название группы без номера;
   - `<test-name>` — название сценария без номера;
   - `<test-file>` — `tests/<kebab-case-группы>/<kebab-case-сценария>.spec.ts`;
   - `<seed-file>` — seed из плана (по умолчанию `tests/seed.spec.ts`);
   - `<body>` — шаги и ожидаемые результаты сценария дословно из плана.
   Агенты используют общий браузер MCP-сервера, поэтому запускай их **последовательно**, по одному.
4. Пропускай сценарии, для которых файл теста уже существует, если пользователь явно не попросил перегенерировать.

В конце выведи таблицу: сценарий → файл → статус (создан / пропущен / ошибка) и предложи `/test-heal` для прогона и починки.
